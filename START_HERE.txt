ALPHA QUEST EDITOR - v0.8.0-alpha - ONEFILE RELEASE KIT
=======================================================

WINDOWS - GERAR UM UNICO .EXE
-----------------------------
1. Extraia este projeto.
2. Dê dois cliques em BUILD_RELEASE.bat.
3. Aguarde testes + PyInstaller.
4. O arquivo para distribuir estará em:

   release\AlphaQuestEditor-v0.8.0-alpha-Windows-x64.exe

Esse é o arquivo que você pode copiar sozinho para a Área de Trabalho,
outro PC ou anexar diretamente em uma GitHub Release. Ele NÃO precisa da
pasta build/, dist/_internal ou DLLs ao lado.

IMPORTANTE
----------
A pasta build/ é temporária do PyInstaller e NÃO deve ser distribuída.
A pasta dist/ contém a saída bruta do build. No modo ONEFILE, ela terá o
AlphaQuestEditor.exe único, mas prefira distribuir o EXE renomeado dentro
de release/.

O modo onefile extrai internamente bibliotecas para uma pasta temporária
enquanto o programa está rodando. Isso é normal e invisível para o usuário.
Por isso, a primeira abertura pode ser um pouco mais lenta que o modo onedir.

CODIGO-FONTE
------------
BUILD_RELEASE.bat também gera:
release\AlphaQuestEditor-v0.8.0-alpha-Source.zip

LINUX
-----
Em Linux:
chmod +x build_linux.sh
./build_linux.sh

Saída:
release/AlphaQuestEditor-v0.8.0-alpha-Linux-x64

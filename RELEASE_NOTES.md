# Alpha Quest Editor v0.10.0-alpha

A **0.10.0-alpha** marca a primeira identidade visual oficial do Alpha Quest Editor e mantém toda a matriz de portabilidade e recursos da 0.9.8.

## Identidade visual oficial

- Novo ícone oficial do Alpha Quest Editor.
- Ícone integrado ao **executável Windows** gerado pelo PyInstaller.
- Ícone aplicado à janela PySide6 e ao aplicativo em runtime.
- `AppUserModelID` próprio no Windows para melhorar a identificação na taskbar/Alt+Tab.
- Recurso PNG incluído corretamente dentro do build **ONEFILE**.
- GitHub Pages/documentação recebe favicon e imagem oficial.
- Pacote `resources/` incluído no código-fonte para builds feitos pela comunidade.

## Recursos mantidos

A versão continua incluindo editor visual, SNBT/JSON5, Port Universal 1.20 → 1.21 ↔ 26.1.2, tradução/QA, Lang Splitter, assets/KubeJS, Dependency Mapper, seleção em lote, Undo/Redo, temas, logs, escrita atômica e build Windows/Linux.

## Build

No Windows, execute `BUILD_RELEASE.bat`. O resultado continua sendo um único arquivo `AlphaQuestEditor-v0.10.0-alpha-Windows-x64.exe`, agora já com o ícone oficial incorporado.

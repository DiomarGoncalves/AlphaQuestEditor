# Alpha Quest Editor v0.8.0-alpha — Public Preview

Primeira versão preparada para distribuição pública.

## Destaques

- Editor visual externo de Quest Books do FTB Quests.
- Canvas com movimentação de quests e dependências.
- Criação, duplicação e exclusão de quests.
- Grupos e capítulos.
- Tasks e Rewards.
- Catálogo pesquisável de itens do Minecraft/modpack.
- Cache de itens e texturas sob demanda.
- Seleção múltipla, alinhamento, distribuição, gaps e snap.
- Dependências em lote.
- Ctrl+Z / Ctrl+Y.
- Editor de traduções PT-BR / EN-US.
- Exportação/importação de relatórios CSV/JSON.
- Workspace responsivo e painéis ocultáveis.
- Validação e backups automáticos.

## Compatibilidade principal

Desenvolvido e testado principalmente para Minecraft 1.21.1 + NeoForge + FTB Quests 2101.x.

## Aviso

Esta é uma versão alpha. Faça backup do Quest Book antes de utilizar em projetos importantes.

Alpha Quest Editor é uma ferramenta comunitária independente e não é um produto oficial da FTB.
